## [慕尼黑市通过开源休假计划资助 `libexpat` 开发](https://blog.hartwork.org/posts/libexpat-city-of-munich-open-source-sabbatical/) ⭐️ 8.0/10

慕尼黑市宣布将通过其“开源休假”计划，资助关键开源 XML 解析器 `libexpat` 的开发长达六个月。这一举措代表了公共部门支持基础软件基础设施的一种新颖模式。 这种资助模式意义重大，因为它展示了公共部门对维护关键基础开源软件的直接投资，而这类软件通常缺乏稳定的财政支持。它可能会激励其他城市或政府采取类似策略，以确保重要的数字基础设施。 这笔资金将为 `libexpat` 提供长达六个月的专属开发时间，`libexpat` 是一个用 C99 编写的流式 XML 1.0 解析器，广泛应用于 Apache、Mozilla、Python 和 PHP 等主要开源项目。该“开源休假”计划对慕尼黑市员工和外部开发者开放，旨在支持对关键开源项目的集中改进工作。

hackernews · spyc · 8月4日 23:18 · [社区讨论](https://news.ycombinator.com/item?id=49176606)

**背景**: `libexpat` 是一个用 C 语言编写的基础性开源 XML 1.0 解析器库，以其高效和流式处理能力而闻名，是许多广泛使用的软件项目中的关键组件。而“开源休假”是慕尼黑市提供的一项计划，旨在为软件开发者提供专门的时间和资源，让他们在有限的期限内为开源项目做出贡献并加以改进。
