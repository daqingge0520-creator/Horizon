## [Cloudflare 收购 Deno，一年后终止其运行时开发](https://deno.com/blog/cloudflare) ⭐️ 9.0/10

Cloudflare 已收购 Deno，但宣布在提供一年的错误修复和安全更新支持后，将停止 Deno 运行时的活跃开发。此举实际上标志着 Deno 运行时由其原始团队进行新功能开发的终结。 此次收购意义重大，因为它实际上停止了 Deno 这一广泛使用的 JavaScript 运行时的创新，令其用户群感到失望，并可能改变服务器端 JavaScript 开发的格局。它影响了那些依赖 Deno 独特功能、安全模型和对现代运行时最初愿景的开发者。 Cloudflare 将为 Deno 运行时提供一年的支持，每月发布专注于错误修复和安全更新的版本，此后开发将停止，尽管 Deno 将保持开源。社区认为这是一次“人才收购”，并对 Deno 安全机制和最初愿景的丧失表示担忧，特别是其转向 npm 兼容性之后。

hackernews · ilreb · 10月9日 13:03 · [社区讨论](https://news.ycombinator.com/item?id=50019911)

**背景**: Deno 是一个安全的 JavaScript、TypeScript 和 WebAssembly 运行时，由 Node.js 的原始开发者 Ryan Dahl 创建，使用 V8、Rust 和 Tokio 构建。它旨在通过提供一个更安全、更现代的开发环境，内置工具和一流的 TypeScript 支持，来解决 Node.js 中存在的感知缺陷。

**社区讨论**: 社区对 Deno 活跃开发被有效终止表示深切的失望和悲伤，认为这是一次“人才收购”，将扼杀创新。许多用户对 Deno 安全特性和最初愿景的丧失感到惋惜，尤其是在其转向 npm 兼容性之后，并质疑 Cloudflare 从此举中获得的战略收益。
